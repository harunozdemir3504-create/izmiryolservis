## 💻 Nasıl Çalıştırılır?

Bu proje bağımsız bir statik web uygulamasıdır. Herhangi bir ekstra kurulum yapmadan:

1. `index.html` dosyasına çift tıklayarak istediğiniz tarayıcıda (Chrome, Edge, Safari vb.) doğrudan açabilirsiniz.
2. Veya yerel bir HTTP sunucusu ile çalıştırmak isterseniz:
   ```bash
   npx serve .
   # veya
   python -m http.server 8000
   ```
3. Web sitenizi Vercel, Netlify, GitHub Pages veya herhangi bir cPanel/Hostinger hostinge `index.html`, `style.css` ve `script.js` dosyalarını yükleyerek anında yayına alabilirsiniz.
